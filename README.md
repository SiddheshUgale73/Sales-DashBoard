# 📊 Sales Analytics Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive **Sales Analytics Dashboard** built using **Power BI** to analyze business performance for the financial year **2022–2023**.

The dashboard helps stakeholders monitor revenue, cost, product performance, and geographic distribution of sales to support data-driven decision-making.

---

## 🎯 Objectives

* Track overall business performance
* Identify top performing product categories
* Analyze brand contribution to revenue
* Monitor state-wise sales distribution
* Evaluate profitability using cost vs sales comparison

---

## 🛠️ Tools & Technologies Used

* **Power BI** – Data visualization & dashboard creation
* **Excel / CSV Dataset** – Data source
* **Data Cleaning & Modeling** – Power Query Editor
* **DAX Measures** – KPI calculations

---

## 📊 Dashboard Features

### Key KPIs

* **Total Sales:** 99M
* **Total Cost:** 76M
* **Total Quantity Sold:** 5095
* **Total Orders:** 5095

### Visualizations Included

* Category-wise quantity analysis (Bar Chart)
* Brand-wise sales contribution (Pie Chart)
* State-wise sales distribution (Map Visualization)
* Summary KPI cards

---

## 🧠 Insights Generated

* Certain hardware components contribute majority of quantity sold
* Few brands dominate total revenue share
* Sales concentration is higher in specific geographic regions
* Profit margin can be evaluated by comparing cost vs sales

---

## 📂 Dataset Description

The dataset contains transactional sales data including:

* Product & Category
* Brand
* Customer
* Quantity
* Cost & Sales Amount
* Order Number
* State/Location

## 🚀 How to Use

1. Download the `.pbix` file from this repository

3. Refresh data if needed
4. Interact with filters and visuals
